# Personal Finance Tracker

A comprehensive **Personal Finance Management Application** built with **React.js**. This app helps users track their income, expenses, and budgets with visual analytics and real-time alerts.


🔗 **Live Demos:**
- [View on Netlify](https://finance-tracker-assignment7.netlify.app/)
- [View on Vercel](https://assignment-7-finance-tracker.vercel.app/)

## Key Features

* **Dashboard Analytics:** Visual overview of Income, Expenses, and Savings using interactive charts (**Recharts**).
* **Transaction Management:** Add, delete, and view detailed logs of daily transactions.
* **Budget Control:** Set monthly budgets for specific categories (e.g., Food, Travel) and get **Toast Alerts** if the limit is exceeded.
* **Data Persistence:** Uses **LocalStorage** to save data, so you never lose your records upon refresh.
* **Responsive Design:** Fully optimized for mobile and desktop views.

## Tech Stack

* **Frontend:** React.js (Context API for State Management)
* **Charts:** Recharts (Pie Chart, Bar Chart)
* **Notifications:** React Toastify
* **Routing:** React Router DOM
* **Styling:** CSS3 (Grid & Flexbox)
